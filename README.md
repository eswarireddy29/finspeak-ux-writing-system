# FinSpeak — UX Writing System

## Overview
A complete UX writing system for a personal finance mobile app targeting first-time savers in India.

## Problem
Finance apps use jargon that confuses non-English users and first-time savers — leading to drop-offs during onboarding and budget setup.

## My Role
UX Writer — wrote all microcopy, built voice & tone guide, ran A/B copy testing, localized content into Telugu and Hindi.

## What's Inside
- Voice & Tone Guide (5 emotional contexts)
- 60+ microcopy elements
- Onboarding flow copy (5 screens)
- Error & empty state library
- A/B copy testing results
- Localization in Telugu & Hindi

## Key Results
- Task completion improved from 61% to 84% after copy iteration
- 8 non-English users tested — all completed core flows without help

## Tools Used
Figma, Notion, Maze (usability testing)
